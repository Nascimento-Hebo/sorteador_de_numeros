<h1>🎲 Sorteador de Números</h1>

<p>
Este projeto foi desenvolvido com foco em praticar desenvolvimento web moderno,
responsividade e manipulação do DOM utilizando JavaScript.
</p>

<p>
A aplicação permite realizar sorteios numéricos de forma simples, rápida e intuitiva,
com uma interface moderna inspirada em design futurista e glassmorphism.
</p>

<h2> Tecnologias Utilizadas</h2>

<ul>
    <li>HTML5</li>
    <li>CSS3</li>
    <li>JavaScript</li>
</ul>

<h2> O que aprendi neste projeto</h2>

<ul>
    <li>Estruturação semântica com HTML</li>
    <li>Estilização moderna com CSS</li>
    <li>Responsividade para dispositivos móveis</li>
    <li>Manipulação do DOM com JavaScript</li>
    <li>Lógica de sorteio numérico</li>
    <li>Criação de interfaces mais profissionais</li>
</ul>

<h2> Destaques do Projeto</h2>

<ul>
    <li>Interface moderna e elegante</li>
    <li>Design responsivo para mobile e desktop</li>
    <li>Efeitos visuais com gradientes e sombras</li>
    <li>Experiência de usuário simples e intuitiva</li>
</ul>

<p>
Este projeto representa mais um passo na minha evolução como desenvolvedor Front-End.
</p>
